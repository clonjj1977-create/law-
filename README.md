# 해양경찰 법령정보센터 (Korea Coast Guard Law Information Center)

**해양경찰 법령정보센터**는 법제처 국가법령정보센터의 UI/UX를 벤치마킹하여, 해양경찰 관련 **법령**과 **행정규칙** 파일을 로컬 PC 환경에서 안전하고 빠르게 업로드·관리·검색·열람할 수 있도록 구축한 독립형(Local Standalone) 웹 애플리케이션입니다.

---

## 1. 주요 특징

* **로컬 PC 단독 운영**: 외부 인터넷이나 별도의 무거운 DB 서버 설치 없이, PC에 설치된 Node.js(내장 SQLite 및 파일 시스템)만으로 즉시 구동됩니다.
* **직관적인 화면 구성**:
  * **홈 화면**: `'해양경찰 법령정보센터'` 타이틀, `'법령'` 및 `'행정규칙'` 상단 메뉴, 통합/분류별 검색 입력창 제공
  * **카테고리 목록 화면**: `'법령'` 또는 `'행정규칙'` 메뉴 클릭 시 새 화면에 관련 파일 목록을 표시하며, **홈 화면으로 돌아가기** 기능 제공
  * **검색 결과 화면**: 키워드로 법령명·본문·소관부서를 검색하여 새 화면에 결과 목록 및 검색어 하이라이트(`#FD3C2D`) 표시
  * **법령 상세 열람 화면 (새 창)**: 목록에서 원하는 항목 클릭 시 **새 창(팝업/새 탭)**에 법제처 스타일(좌측 검색결과/목차 연동 + 우측 본문/조문/소관부서/화면내 검색/인쇄/다운로드)로 상세 내용을 표시
  * **관리자 화면**: 법령 및 행정규칙 파일을 수동으로 업로드하여 로컬 스토리지(`storage/`) 및 로컬 DB에 저장·수정·삭제 관리
* **전용 컬러 팔레트 적용**:
  * Deep Brown (`#724D45`), Deep Forest Green (`#04503E`), Deep Teal Green (`#045043`), Coral Orange (`#FE8650`), Vivid Red-Orange (`#FD3C2D`) 색상 테마 적용

## 3. 빠른 시작 (Quick Start)

### 3.1 실행 환경 요구사항
* **OS**: Windows 10 / 11
* **Node.js**: `v24.22.1` 이상 (내장 `node:sqlite`, `node:http`, `node:fs` 활용)
* **Git**: `v2.55.0` 이상 (버전 관리용)
* **브라우저**: Microsoft Edge, Google Chrome 등 최신 웹 브라우저

### 3.2 서버 실행 방법
터미널(PowerShell 또는 명령 프롬프트)에서 프로젝트 루트(`c:\edu_test`)로 이동한 후 아래 명령어를 실행하거나 `start.bat` 파일을 더블클릭합니다.

```powershell
node src/server.js
```

서버가 실행되면 웹 브라우저에서 아래 주소로 접속합니다.
* **사용자 메인 화면**: `http://localhost:3001/`
* **관리자 파일 업로드 화면**: `http://localhost:3001/admin.html`

## 4. 기본 제공 샘플 데이터

최초 실행 시 즉시 검색 및 열람 테스트가 가능하도록 해양경찰 관련 대표 법령 및 행정규칙 샘플이 자동 등록됩니다.
* **법령**: `수상레저안전법`, `수상레저안전법 시행령`, `수상레저안전법 시행규칙`, `해양경비법`, `수상에서의 수색·구조 등에 관한 법률`
* **행정규칙**: `해양경찰청 수상레저 안전관리 규정`, `해양경비 안전활동 규칙`, `파출소 및 출장소 운영 규칙`
